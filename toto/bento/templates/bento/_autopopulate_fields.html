{% comment %} Live auto-fill of trivially-derived template fields from the Name input. Mirrors the server-side helpers in bento/models.py (Django slugify / default_label / default_rel_type) so a creator sees the slug, Neo4j label and rel_type appear as they type the name. Each target is filled only while it is "pristine" (empty at page load — i.e. a fresh create form). Opening an existing record (edit form: fields already populated) or editing a field by hand stops that field's sync, so values are never clobbered. Anything still left blank is re-derived server-side on save, so this is purely a convenience preview. {% endcomment %}
