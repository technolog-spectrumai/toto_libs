That is the whole rule. Marking everything unknown would put a symbol on almost every row on day one, and a warning that is always on is a warning nobody reads. Absence means "not looked at", and it looks exactly like the interface did before this app existed. Expects: file (a VaultFile) and clean_ids (a set of pks, from toto.vault.scanning.clean_file_ids).
