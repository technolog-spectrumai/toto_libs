{% comment %} The Office tab strip. It lives in oya/ rather than in any one app for the reason _economy_tabs.html states at length: Django only loads the template directories of INSTALLED apps, so a strip that spans several wheels and a host portion would vanish the moment its home app was switched off. Documents come from toto-works, sheets from a zenobia host portion, drawings from nowhere in particular — no app can own this. The tabs themselves are built in the view (core.views.office_view via core.office.available_sections), not guarded here: whether a host serves a tab is a question about INSTALLED_APPS, and answering it in a template means answering it again in every other template that ever wants to know. {% endcomment %} {% load i18n %}
