{% load i18n app_tags %} {% comment %}ONE strip for the productivity apps — the Office area. Caller passes active_tab = documents | presentations | sheets | drawings | html. Each entry is doubly guarded, and both guards are load-bearing (the same pair oya/_economy_tabs.html uses, and for the same reasons): * `|app_installed` hides the tab when the app is not in INSTALLED_APPS; * the `{% templatetag openblock %} url … as {% templatetag closeblock %}` form swallows NoReverseMatch, so an app that is installed but mounted at no URL degrades to no tab rather than a 500. It lives in toto-base/oya/ rather than in any one of the five apps: they are spread across toto-works (cyprian, memo, primula, sketch) and toto-base (aralia is a host app on zenobia), and Django only loads template dirs for INSTALLED apps — so a strip owned by one of them would vanish on a host that did not install that one. Same siting, and the same reasoning, as the economy and media strips. Written as a comment tag rather than a hash-brace comment because that form is single-line only; spanning one over several lines makes Django render the whole block as visible page text.{% endcomment %}
