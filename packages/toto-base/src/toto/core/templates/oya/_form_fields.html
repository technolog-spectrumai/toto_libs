{% load i18n %} {% comment %}Django-rendered form fields, made theme-aware. Caller passes: form. Optionally submit_label (default "Save") and submit_name/submit_value for a hidden action field. WHY THIS EXISTS. `{{ form.as_p }}` emits bare widgets with no classes at all. Tailwind's preflight sets `color: inherit` on form controls but leaves `` with the user agent's own background — white — so on a dark page every Django-rendered field is light text in a white box. Nothing about that is visible in the template that renders it, which is why it keeps coming back: the bug is in what Django writes, not in what anybody typed. The fix is the one tariffs/tariff_form.html found: an Alpine-bound wrapper carrying the colours, and arbitrary-variant selectors telling the widgets inside to inherit them. `bg-inherit`/`text-inherit`/`border-inherit` is what makes it work — a static class could not follow `darkMode`, and the widgets cannot carry an `:class` because Django writes them. Any template rendering a whole Django form should include this rather than calling `.as_p` itself, so the next one cannot reintroduce it.{% endcomment %}
