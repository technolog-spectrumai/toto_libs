{% load i18n %} {% comment %}Versions panel + editing-lock banner, shared by every vault editor. Caller passes: file_pk, and optionally can_write (defaults to true). can_write is honoured since 2026-09-30 — it used to be accepted and ignored, so a reader of somebody's public drawing claimed its lock just by opening the page. False makes this a reader's panel: the history and who is editing, no lock claimed, no "Save version", no "Restore". The server narrows it further on its own answers (oya/file_versions.js), because the vault's doors refuse a reader whatever the page said. Lives in oya/ rather than in cyprian, memo or primula for the reason oya/_media_tabs.html records: Django loads template dirs only for INSTALLED apps, so a partial living in one editor's templates vanishes on a host that does not install that editor — and this one is included by three of them, none of which is guaranteed present. .gitignore's `media/` rule matching at any depth is the second reason a shared partial cannot live just anywhere. Everything here talks to toto.vault's endpoints. The editors supply only the file id; they do not each reimplement heartbeat, release or restore, which is precisely how primula ended up with versioning the other two never got. Dark/light stays Alpine; state comes from the server.{% endcomment %}
