Sub-tabs stay where they are — each app's own base.html keeps its {% templatetag openblock %} block tab_x {% templatetag closeblock %} row. This is only the top level. Each entry is doubly guarded, and both guards are load-bearing (the oya/_media_tabs.html reasoning, which applies here with more force because the economy spans three packages): * `|app_installed` hides the tab when the app is not in INSTALLED_APPS; * the `url … as` form swallows NoReverseMatch, so an app that is installed but mounted at no URL degrades to no tab rather than a 500. It lives in toto-base/oya/ and not in toto.assets for the same two reasons _media_tabs.html records. Django loads template dirs only for INSTALLED apps, and this bar must render on placidia — which pins toto-economy but installs only assets and tariffs — and on any host that has toto.quota and nothing else. And .gitignore carries a `media/` rule that matches at any depth, so a shared partial must not live under a templates/media/ path; oya/ is where core's shared templates already live. The strip spans four packages: toto.assets and toto.tax (toto-economy), toto.quota (toto-base, on every host), and toto.bourse / toto.portfolio (zenobia's own portion). That spread is exactly why this is an included partial rather than a base template with blocks — a base template would have to live in one of those packages and would vanish with it. ROLE SPLIT. Staff and users get the same three tabs pointing at different places, because the destinations differ in kind rather than in permission: a user's "Usage" is their own consumption, staff's is the platform's records. Fees is one URL for both — the view renders income and editors for staff, and "what am I charged, and why" for everyone else. Hiding a tab is cosmetic; every destination enforces its own gate, so a hand-typed URL is still refused. Active state is decided server-side; dark/light stays Alpine (darkMode). Written as a comment tag rather than a hash-brace comment because that form is single-line only — spanning one over several lines makes Django render the whole block as visible page text.{% endcomment %}
