{% comment %} The Monitoring tab strip: Monitoring | Database | Audit | History. It lives in oya/ for the reason _office_tabs.html states: Django only loads the template directories of INSTALLED apps, and this strip spans two wheels — Monitoring, Database and History come from toto.monit (toto-ops), Audit from toto.audit (toto-base) — so no one app can own it. The tabs themselves are built in the view (core.monitoring.monitoring_tabs), not guarded here, and that builder does one thing Office's does not: it filters by the VIEWER's role, because the tabs' own gates differ — monit's pages are superuser-only, audit's are staff. A staff-not-superuser therefore sees a one-tab strip rather than three refusals, which is the forum's hide-don't-refuse convention. Each page passes its own `monitoring_tabs` from monitoring_tabs(user, active=…); the active tab is decided there and never from the request path — the tabs live in two apps under two prefixes, so there is no one path to compare against. {% endcomment %} {% load i18n %}
