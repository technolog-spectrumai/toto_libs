Pierwsze kroki

Po zalogowaniu trafiasz na Pulpit — siatkę kart, po jednej dla każdego modułu zainstalowanego na tym serwerze. Kliknij kartę, aby otworzyć moduł. Nagłówek u góry każdej strony prowadzi z powrotem do Pulpitu i do Twojego profilu.

  • Moduły są pogrupowane w kategorie; grupy można zwijać i rozwijać.
  • Widoczne są tylko moduły zainstalowane na tym serwerze — ta sama zasada dotyczy tego podręcznika.
  • Przełącznik motywu w nagłówku zmienia tryb jasny/ciemny.
{% if features.socialhub %}

Profil i społeczności (Portal społeczny)

Otwórz Mój profil z nagłówka, aby zobaczyć swoją stronę członkowską: dane, społeczności, do których należysz, oraz aktywność referencyjną. Portal społeczny zawiera listę wszystkich profili członków i społeczności.

  • Język — na własnym profilu wybierz preferowany język (polski lub angielski). Cały interfejs przełącza się natychmiast, a wybór zostaje zapamiętany.
  • Społeczności — przeglądaj społeczności i składaj wnioski o członkostwo. Wniosek może wymagać kodu weryfikacyjnego oraz referencji od obecnych członków.
  • Referencje — gdy ktoś wskaże Cię jako osobę polecającą, prośba pojawi się na Twoim profilu; tam ją akceptujesz lub odrzucasz.
{% endif %} {% if features.gervazy %}

Moje klucze (szyfrowanie)

Strona Moje klucze (dostępna z Twojego profilu) służy do zarządzania kluczami szyfrującymi, które chronią Twoje dane. Pliki w przechowywaniu można nimi szyfrować i odszyfrowywać — bez kluczy serwer przechowuje wyłącznie nieczytelny szyfrogram.

{% endif %} {% if features.vault %}

Przechowywanie (Vault)

Przechowywanie gromadzi Twoje pliki w drzewie katalogów. Możesz je wgrywać, pobierać, przenosić i usuwać oraz szyfrować swoimi kluczami. Zależnie od typu pliku obok pojawiają się dodatkowe przyciski Odtwórz / Edytuj:

    {% if features.vod %}
  • Wideo — pliki wideo odtwarzane są bezpośrednio w przeglądarce.
    • {% endif %}
  • Obrazy — obrazy otwierają się w oknie podglądu.
    • {% if features.memo %}
  • Prezentacje — pliki prezentacji .pml: Odtwórz uruchamia pokaz slajdów, Edytuj otwiera edytor slajdów.
    • {% endif %} {% if features.notarius %}
  • Kontrakty — dokumenty .contract można przeglądać, edytować i podpisywać.
    • {% endif %} {% if features.editor %}
  • Pliki tekstowe — pliki tekstowe, JSON, YAML, XML, CSV i HTML otwierają się we wbudowanym edytorze.
    • {% endif %} {% if features.sketch %}
  • Szkice — rysunki SVG otwierają się na wspólnej tablicy do rysowania.
    • {% endif %} {% if features.notebooks %}
  • Notatniki — notatniki .tpy łączą komórki z kodem i ich wyniki; edytuj je i uruchamiaj w edytorze notatników.
    • {% endif %} {% if features.latex %}
  • LaTeX — edytuj pliki .tex z podglądem na żywo i kompiluj je do PDF.
    • {% endif %} {% if features.pyeditor %}
  • Python — edytuj i uruchamiaj skrypty .py bezpośrednio z przechowywania.
    • {% endif %} {% if features.fileservices %}
  • Usługi plikowe — przycisk różdżki uruchamia usługę na pliku (np. konwersję lub analizę mediów, rozpoznawanie tekstu, transkrypcję — zależnie od konfiguracji serwera). Wyniki zapisywane są jako nowe pliki.
    • {% endif %}
{% endif %} {% if features.events %}

Zdarzenia

Zdarzenia to lista nadchodzących i minionych wydarzeń wraz ze szczegółami. Otwórz wydarzenie, aby zobaczyć kiedy i gdzie się odbywa; nadchodzące wydarzenia powiązane z Tobą widać też na Twoim profilu.

{% endif %} {% if features.kanban %}

Zadania

Zadania to tablica kanban. Wybierz projekt, aby otworzyć jego tablicę, a następnie przesuwaj karty zadań między kolumnami w miarę postępu prac.

  • Twórz zadania w kolumnie i przeciągaj je po tablicy.
  • Dłuższe przedsięwzięcia organizuj w kampanie, misje i sprinty.
{% endif %} {% if features.locations %}

Lokalizacje

Lokalizacje to interaktywna mapa punktów, terytoriów, tras i adresów. Przeglądaj mapę, sprawdzaj miejsca i wyszukuj trasy między lokalizacjami.

{% endif %} {% if features.polls %}

Ankiety

Ankiety to interaktywne głosowania: otwórz ankietę, oddaj głos i śledź wyniki.

{% endif %} {% if features.chat %}

Czat

Czat podzielony jest na kanały. Dołącz do kanału, aby czytać i pisać wiadomości — nowe wiadomości pojawiają się na żywo, bez przeładowania strony.

{% endif %} {% if features.workflows %}

Przepływy pracy

Przepływy pracy pozwalają budować i uruchamiać zautomatyzowane potoki: połącz kroki przetwarzania w graf, uruchom go i śledź przebieg oraz wyniki każdego uruchomienia.

  • Każde uruchomienie jest zapisywane — otwórz je, aby sprawdzić status i wynik każdego kroku.
  • Niektóre moduły (np. usługi plikowe) automatycznie uruchamiają swoje zadania jako przepływy pracy, więc tutaj też można je śledzić.
{% endif %} {% if features.graph %}

Graf wiedzy

Graf wiedzy przechowuje obiekty i ich powiązania w postaci grafu, który można przeszukiwać, edytować i analizować. Strona podzielona jest na zakładki:

  • Zapytania — przeszukuj graf lub wykonuj zapytania Cypher i przeglądaj wyniki wizualnie.
  • Dane — przeglądaj i edytuj graf: definiuj kategorie węzłów i typy krawędzi, a następnie dodawaj i zmieniaj węzły oraz krawędzie.
    • {% if features.workflows %}
  • Analiza — uruchamiaj gotowe analizy grafu; wyniki zapisywane są w przechowywaniu.
    • {% endif %}
  • Wiedza — wklej tekst, a platforma zaproponuje encje i relacje; przejrzyj propozycję na kanwie i zastosuj ją do grafu.
    • {% if features.ocr %}
  • OCR — wgraj zrzut ekranu lub zdjęcie, wydobądź z niego tekst i przekaż go do powyższego potoku wiedzy.
    • {% endif %}
  • Obiekty w innych częściach platformy (np. zdarzenia czy lokalizacje) mają przycisk Eksportuj do grafu, który dodaje je do grafu wraz z bezpośrednimi powiązaniami.
{% endif %} {% if features.manta %}

Narzędzia mediów (Manta)

Manta to kreator poleceń do pracy z mediami: zbuduj zadanie konwersji, analizy, transkrypcji lub rozpoznawania tekstu na plikach z przechowywania, obejrzyj dokładne polecenie na żywo i uruchom je. Wyniki zapisywane są z powrotem w przechowywaniu.

{% endif %} {% if features.steven %}

Asystent (Steven)

Steven to czatowy asystent platformy. Otwórz go pływającym przyciskiem w rogu dowolnej strony i zadawaj pytania zwykłym językiem — odpowiada z użyciem backendu AI skonfigurowanego na tym serwerze.

{% endif %} {% if features.grafana %}

Monitorowanie (administratorzy)

Karta Monitorowanie na Pulpicie otwiera Grafanę z metrykami i logami serwera. Jest dostępna wyłącznie dla superużytkowników i loguje Cię kontem platformy.

{% endif %}
