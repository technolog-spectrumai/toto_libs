Getting started

After signing in you land on the Dashboard — a grid of cards, one per module installed on this server. Click a card to open the module. The header at the top of every page takes you back to the Dashboard and to your profile.

  • Modules are grouped into categories; you can collapse or expand the groups.
  • Only modules installed on this server appear — the same rule applies to this manual.
  • Use the theme switch in the header to toggle between light and dark mode.
{% if features.socialhub %}

Profile & communities (SocialHub)

Open My Profile from the header to see your member page: your details, the communities you belong to, and your reference activity. The SocialHub lists all member profiles and communities.

  • Language — on your own profile, pick your preferred language (Polish or English). The whole interface switches immediately and the choice is remembered.
  • Communities — browse communities and apply for membership. An application may require a verification code and references from existing members.
  • References — when someone names you as a reference, the request appears on your profile; accept or reject it there.
{% endif %} {% if features.gervazy %}

My Keys (encryption)

The My Keys page (linked from your profile) manages the encryption keys that protect your data at rest. Files in the storage can be encrypted and decrypted with these keys — without them the server stores only unreadable ciphertext.

{% endif %} {% if features.vault %}

Storage (Vault)

The Storage keeps your files in a folder tree. Upload, download, move and delete files, and encrypt them with your keys. Depending on the file type, extra Play / Edit buttons appear next to a file:

    {% if features.vod %}
  • Video — video files play directly in the browser.
    • {% endif %}
  • Images — images open in a preview window.
    • {% if features.memo %}
  • Presentations — .pml presentation files: Play starts the slideshow, Edit opens the slide editor.
    • {% endif %} {% if features.notarius %}
  • Contracts — .contract documents can be viewed, edited and signed.
    • {% endif %} {% if features.editor %}
  • Text files — text, JSON, YAML, XML, CSV and HTML files open in the built-in editor.
    • {% endif %} {% if features.sketch %}
  • Sketches — SVG drawings open on a collaborative whiteboard.
    • {% endif %} {% if features.notebooks %}
  • Notebooks — .tpy notebooks combine code cells with their outputs; edit and run them from the notebook editor.
    • {% endif %} {% if features.latex %}
  • LaTeX — edit .tex files with a live preview and compile them to PDF.
    • {% endif %} {% if features.pyeditor %}
  • Python — edit and run .py scripts straight from the storage.
    • {% endif %} {% if features.fileservices %}
  • File services — the wand button runs a service over a file (e.g. media conversion or info, text recognition, transcription — depending on server configuration). Results are saved back as new files.
    • {% endif %}
{% endif %} {% if features.events %}

Events

Events lists upcoming and past events with their details. Open an event to see when and where it takes place; upcoming events connected to you also show up on your profile.

{% endif %} {% if features.kanban %}

Tasks

Tasks is a kanban board. Pick a project to open its board, then move task cards between columns as work progresses.

  • Create tasks in a column and drag them across the board.
  • Organise longer efforts with campaigns, missions and sprints.
{% endif %} {% if features.locations %}

Locations

Locations is an interactive map of points, territories, routes and addresses. Browse the map, inspect places, and search for routes between locations.

{% endif %} {% if features.polls %}

Polls

Polls hosts interactive polls: open a poll, cast your vote, and watch the results.

{% endif %} {% if features.chat %}

Chat

Chat is organised into channels. Join a channel to read and post messages — new messages appear live, without reloading the page.

{% endif %} {% if features.workflows %}

Workflows

Workflows let you build and run automated pipelines: connect processing steps into a graph, run it, and follow each run's progress and results.

  • Every run is recorded — open it to inspect the status and output of each step.
  • Some modules (for example file services) run their jobs as workflows automatically, so you can track them here too.
{% endif %} {% if features.graph %}

Knowledge Graph

The Knowledge Graph stores objects and their relationships as a graph you can search, edit and analyse. The page is organised into tabs:

  • Query — search the graph or run Cypher queries and explore the results visually.
  • Data — browse and edit the graph: define node categories and edge types, then add and modify nodes and edges.
    • {% if features.workflows %}
  • Analysis — run predefined graph analyses; results are saved to the storage.
    • {% endif %}
  • Knowledge — paste text and let the platform suggest entities and relations; review the proposal on a canvas and apply it to the graph.
    • {% if features.ocr %}
  • OCR — upload a screenshot or photo, extract its text, and feed it into the knowledge pipeline above.
    • {% endif %}
  • Objects elsewhere in the platform (for example events or locations) offer an Export to graph button that adds them, with their direct connections, to the graph.
{% endif %} {% if features.manta %}

Media toolbox (Manta)

Manta is a command builder for media work: compose conversion, inspection, transcription or text-recognition jobs over files from the storage, preview the exact command live, and run it. Outputs are saved back to the storage.

{% endif %} {% if features.steven %}

Assistant (Steven)

Steven is the platform's chat assistant. Open it with the floating button in the corner of any page and ask questions in plain language — it answers using the AI backend configured on this server.

{% endif %} {% if features.grafana %}

Monitoring (administrators)

The Monitoring card on the Dashboard opens Grafana with the server's metrics and logs. It is available to superusers only and signs you in with your platform account.

{% endif %}
