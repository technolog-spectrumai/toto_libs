Context: slide a presentation_format.Slide theme "black" | "white" font "sans" | "serif" | "mono" | "rounded" | "condensed" trust_html whether a legacy `html` block is rendered live or escaped `trust_html` is the one thing a caller must think about. Every block type is sanitised on the way in, EXCEPT `html` — the v1 escape hatch, which is deliberately preserved verbatim because its trust model is exactly what v1's `{{ slide.body|safe }}` already was. That is defensible in the player, where you have navigated to one deck. It is not defensible in the gallery, which lists *other people's public decks*: one hostile deck would then run script on every visitor. So the gallery passes trust_html=False and gets an inert placeholder. {% endcomment %}
