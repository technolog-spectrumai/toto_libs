Rendered into every authenticated page through {% templatetag openblock %} render_floating_plugins {% templatetag closeblock %}, so it must be entirely self-contained AND entirely unable to take a page down. Three fail-safes, each of which alone keeps the page usable: 1. chat.js loads SYNCHRONOUSLY. oya/alpine.js starts Alpine in a queueMicrotask right after its own (deferred) script runs — BEFORE any later deferred script executes — so a deferred component factory is undefined at init, Alpine strips x-cloak anyway, x-show throws instead of evaluating, and the panel wedges OPEN with dead handlers. That is exactly the outage this file shipped once; sync definition-only scripts are the house pattern (sketch, cyprian) for this reason. 2. x-data falls back to an inert stub when the factory is missing, so every binding still evaluates and the chip is simply dead rather than broken. 3. The panel carries a literal style="display:none" — x-show overrides it when Alpine is in charge, and nothing can render it open when Alpine is not. NO full-screen layer and NO scrim, deliberately: the chat is a corner POPOVER, not a modal. The page behind it stays fully interactive — an assistant must never block the work it is supposed to help with. Close is the ×, Escape, or clicking anywhere else. EPHEMERAL by decision: the transcript lives in Alpine state and dies with the page; every question is a single-turn run ("say"), or a single question about the page's document ("ask") when an editor registered one. Nothing is stored but the usage records every run writes. Slot map, hand-coordinated: gas pump right-6, this chip right-20. {% endcomment %}
